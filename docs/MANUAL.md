# VUメーター 取扱説明書

対象バージョン： v1.22（versionCode 23）
パッケージ名： jp.himawari.vumeter

## 1. 概要

USB オーディオインターフェースの入力を測定する、アナログスタイルの VU メーターアプリです。ヤマキ電気 YVU-110 を参考にしたメーターフェイスに、トゥルーピーク表示の LED メーターと、BS.1770 準拠のラウドネス表示を備えています。

主な機能：

- VU メーター（L+R 合算／L・R 個別の2フェイス表示）
- ラウドネスメーター（ショートターム／Integrated の2本針）
- LED トゥルーピークメーター（ピークホールド付き）
- 数値表示（ピーク dBTP、VU 値、LOUDNESS M／S／I、相関）
- テストトーン発生（100 Hz／1 kHz／10 kHz／ホワイトノイズ／ピンクノイズ）
- 測定値の CSV ログ記録

## 2. 動作環境

- Android 12（API 31）以降
- USB オーディオインターフェース（USB Audio Class 対応機器）
- スマートフォン本体のマイク入力でも測定できます

## 3. インストール

GitHub リリースから `VuMeter.apk` をダウンロードし、インストールしてください。従来のバージョンがインストールされている場合は、そのまま上書きインストールできます（署名が同一のため、設定やデータは引き継がれます）。

初回起動時にマイクの許可を求められた場合は、許可してください（USB インターフェースの音声を取り込むために必要です）。

## 4. 画面の見方

### メイン画面

- **メーターフェイス**：縦画面では L+R 合算の1フェイス、横画面では L／R 別々の2フェイスを表示します（ラウドネス表示の横画面は、左＝ラウドネス合算フェイス、右＝Phase 表示）
- **ピークメーター**：横画面では画面右端の縦型 LED メーター、縦画面ではフェイス下の横型バーで、トゥルーピークのレベルを L／R 表示します。縦型には基準レベル位置に「REF」、−9 dBFS 位置に PML マークを表示します
- **Phase（相関）表示**：縦画面ではフェイス下に相関バー（−1〜+1）、横画面のラウドネス表示では右側にリサージュ（ベクトルスコープ）と相関を表示します
- **HOLD ボタン**（横画面は LED メーター下、縦画面は横型ピークメーターの右端）：ピークホールド表示のオン／オフを切り替えます（オンのとき文字が金色）
- **数値表示**：
  - 大きな数字 … L／R のピーク値（dBTP、トゥルーピーク）
  - VU 値 … L／R の VU 値
  - LOUDNESS … M（モーメンタリ）／S（ショートターム）／I（Integrated、LUFS）
  - CORR … L／R の相関係数（+1.00 に近いほどモノラル寄り、−1.00 に近いほど逆相）
- **現在値の行**：基準レベル（0 VU = ○○ dBFS）と表示モード（VU／ラウドネス）
- **状態ランプと状態行**：ランプは緑＝測定中、赤＝停止中。状態行には録音エンジン、接続デバイス、サンプルレートなどを表示します

### 設定画面

メイン画面を長押し（0.7秒）すると開きます。設定項目の詳細は「7. 設定画面の項目」を参照してください。メイン画面へは、画面下部の「メーターへ戻る」ボタンのほか、Android の戻るボタン／戻るジェスチャーでも戻れます。

## 5. 基本操作

メイン画面の操作はジェスチャーです（ボタンはありません）。

| 操作 | 動作 |
|---|---|
| タップ | VU ⇔ ラウドネスの表示切り替え |
| ダブルタップ | 測定の開始／停止 |
| 長押し（0.7秒） | 設定画面を開く（押した位置に進捗リングが表示され、途中で指を離す／ずらすとキャンセル） |
| ピークメーターをダブルタップ | ピークと Integrated のリセット |
| HOLD ボタン | ピークホールド表示のオン／オフ |

## 6. VU メーターの見方

- 目盛は 0 VU を基準に、−20〜+3 VU の範囲を表示します。0〜+3 は太い赤帯です
- 0 VU が表すレベル（基準レベル）は、設定画面で −24／−20／−18／−16／−14 dBFS から選べます（既定は −18 dBFS）
- 針の動きは IEC 60268-17 の VU 特性（300 ms で 99% 到達、オーバーシュート 1.24%）を再現しています

## 7. ラウドネスメーターの見方

- 針は2本です。**細針＝ショートターム**（直近3秒）、**太針＝Integrated**（測定開始またはリセットからの全区間）
- 目盛は基準値を 0 LU とする相対表示で、範囲は −24〜+6 LU です。0 LU の位置は VU 目盛の 0 の位置と一致し、0〜+6 LU は赤帯です
- フェイスには「LUFS」と「I」（Integrated）の表記があります
- 基準値は設定画面のプリセットから選びます（「8. ラウドネス基準値プリセット」参照）。プリセット名はフェイス下部にも表示されます
- 横画面では、左に合算ラウドネスのフェイス、右に Phase（リサージュ＋相関）を表示します

### ラウドネス基準値プリセット

| プリセット | 基準値 | 用途の目安 |
|---|---|---|
| ARIB TR-B32（日本・放送） | −24 LKFS | 日本の放送 |
| EBU R 128（欧州・放送） | −23 LUFS | 欧州の放送 |
| ATSC A/85（米国・放送） | −24 LKFS | 米国の放送 |
| ライブ・PA（目安） | −18 LUFS | ライブ、PA 現場 |
| YouTube | −14 LUFS | 動画配信 |
| Spotify | −14 LUFS | 音楽配信 |
| Amazon Music | −14 LUFS | 音楽配信 |
| Apple Music | −16 LUFS | 音楽配信 |
| Netflix | −27 LUFS | 映像配信（ダイアログ基準） |

## 8. 設定画面の項目

- **基準レベル**：0 VU に対応するレベルをスライドスイッチで選択（−24／−20／−18／−16／−14 dBFS）。基準レベル／表示モード／ラウドネス基準値プリセットは保存され、次回起動時も保持されます
- **表示モード**：VU／ラウドネスの切り替えと、ラウドネス基準値プリセットの選択
- **測定開始／停止**：メイン画面のダブルタップと同じ操作です
- **ピーク リセット**：保持ピークとクリップ表示のみをリセットします
- **Integrated リセット**：Integrated ラウドネスの計測だけを最初からやり直します（番組の頭から測り直すときに使います）
- **入力デバイス**：使用する入力デバイスの選択
- **録音エンジン**：AAudio／AudioRecord の選択と、入力プリセット（UNPROCESSED 等）の選択。AAudio で開始できない場合は AudioRecord に自動で切り替わります
- **テストトーン**：100 Hz／1 kHz／10 kHz／ホワイトノイズ／ピンクノイズの発生（出力先デバイスから再生されます）
- **CSV ログ**：測定値の記録開始／停止。ファイル名は `vu_log_YYYYMMDD_HHMMSS.csv` で、ダウンロードフォルダに保存されます
- **操作マニュアル**：設定画面の末尾に、操作一覧の要約があります

## 9. 測定仕様

- トゥルーピーク：4倍オーバーサンプリングによる補間ピーク（dBTP）
- ラウドネス：ITU-R BS.1770 K 特性フィルタ。Integrated は 400 ms ブロック（75% オーバーラップ相当）で、絶対ゲート −70 LUFS／相対ゲート −10 LU の2段階ゲーティングを適用
- VU 針特性：IEC 60268-17 準拠
- LED メーターの戻り特性：IEC 60268-18 方式（20 dB の落下に 1.7 秒）
- サンプルレート：接続デバイスに追従（44.1 kHz／48 kHz／96 kHz 等）

## 10. トラブルシューティング

- **USB インターフェースが認識されない**：USB ケーブルと OTG 接続を確認し、アプリを再起動してください。他のアプリがデバイスを使用中の場合は、そのアプリを終了してください
- **針が動かない**：停止中（ランプが赤）になっていないか確認し、ダブルタップで測定を開始してください。入力デバイスの選択が正しいかも確認してください
- **音が出ない（テストトーン）**：出力先の音量と、インターフェース側の出力設定を確認してください
- **数値が −∞ や −−.− のまま**：無音状態では正常な表示です。信号を入力してください

## 11. 注意事項

- 本アプリの測定値は、接続するインターフェースの性能と設定に依存します。校正済みの測定器の代わりにはなりません
- Integrated ラウドネスは測定開始（またはリセット）からの累積値です。測り直す場合はリセットしてください
- 運転中など、画面注視が危険な状況での操作は避けてください

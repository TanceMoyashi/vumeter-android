# リリース手順

VUメーターの新しいバージョンを公開する手順です。

## バージョン番号の決め方

- `versionName`：利用者向けの表示（例：1.4 → 1.5）。機能追加で小数部を上げる
- `versionCode`：整数。リリースごとに必ず +1 する（Android の更新判定に使われる）

## 手順

### 1. バージョン番号を更新する

- Gradle / Android Studio でビルドする場合：
  `app/build.gradle.kts` の `defaultConfig` にある `versionCode` / `versionName` を更新する
- 開発環境の手動ビルド（`build-apk.sh`）の場合：
  スクリプト内の `aapt2 link` の引数 `--version-code` / `--version-name` で指定する

> 注意：v1.4（versionCode 5）までは実際の配布版を手動ビルド側の引数で
> 指定して作成したため、`app/build.gradle.kts` の値が古いままだった。
> v1.5 で両者を 6 / 1.5 に揃えた。以後のリリースでは両方を一緒に更新すること。

### 2. 変更履歴を書く

`CHANGELOG.md` の先頭に、新バージョンの節を追加する。

### 3. ビルドして署名する

- 署名キー（`vumeter.keystore`）はリポジトリの外で管理しているものを使う
- **別のキーで署名すると、インストール済みのアプリへの上書き更新ができなくなる**
  ため、必ず同じキーで署名する

### 4. 実機で確認する

- [ ] Android 12 以降にインストールできる
- [ ] 本体マイクで針と数値が動く
- [ ] 縦画面＝L+R の1メーター／横画面＝L/R の2メーターに切り替わる
- [ ] USB オーディオ I/F を挿すと一覧に出て、選んで測定できる
- [ ] 校正トーン（1kHz）が聞こえる
- [ ] ログ開始→停止で、ダウンロードフォルダに `vu_log_*.csv` ができる

### 5. ソースコードを GitHub に反映する

変更したファイルをコミット／プッシュする。

### 6. APK を Releases に公開する

1. リポジトリの Releases ページで「Draft a new release」を開く
2. Choose a tag で `v<versionName>`（例：v1.5）と入力し、新規タグを作成する
3. Release title にも同じタグ名を入れる
4. 本文には `CHANGELOG.md` の該当節を貼る。あわせて、README の
   「このアプリについて」（実験的なアプリであること、利用は自己責任、
   更新・バグ対応の保証なし）の要旨も含めること
5. 添付エリアにビルドした `VuMeter.apk` をドラッグ＆ドロップする
6. 「Publish release」を押す

ダウンロードする人は、Releases のページから APK を取得してインストールできる。
（提供元不明アプリのインストール許可が必要な旨を案内すること）
